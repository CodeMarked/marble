# Marble

C++20 game engine with Vulkan and ECS.

## Build

From the project root:

```bash
cmake -B build -S .
cmake --build build --config Release
```

(Debug: use `--config Debug`; exe then at `build\game\Debug\marbles.exe`.)

## Run

`build\game\Release\marbles.exe`

---

If CMake is not recognized, add CMake’s `bin` to your PATH
